# Протокол Ludarex

- Транспорт: TCP, порт 9999
- Первый пакет клиента: имя (без перевода строки)
- Дальше клиент шлёт текст сообщений (без перевода строки)
- Сервер рассылает ВСЕМ: [ЧЧ:ММ] [имя] текст
- Команда /history: сервер присылает историю только этому клиенту
- База: файл chat_db.txt, пары строк «время / текст»
